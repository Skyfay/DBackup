### ✨ Features

- **Cloudflare D1**: New source that backs up and restores the D1 databases of a Cloudflare account through its API, with an API token and nothing to install. A restore keeps the database and its ID and logs a Time Travel bookmark to go back to. ([#202](https://github.com/Skyfay/DBackup/issues/202))

### 📝 Documentation

- **Cloudflare D1**: New source guide with the token setup, the lock during an export and import, and the values the export of Cloudflare cannot carry.
